# Proyecto Big Data - Netflix

## ¿Qué datos genera?

Netflix genera grandes cantidades de datos diariamente.

Entre los datos producidos están:

- Películas y series vistas
- Tiempo de reproducción
- Búsquedas realizadas
- Preferencias de usuarios


### Tipo de datos
- Datos de usuarios
- Datos de comportamiento
- Datos estadísticos

### Volumen
Millones de usuarios generan datos cada día.

### Frecuencia
Los datos se generan en tiempo real las 24 horas.



## ¿Quién los usa?

Los datos son utilizados por:

- Netflix
- Analistas de datos
- Ingenieros
- Sistemas de inteligencia artificial
- Equipos de marketing



## ¿Qué problema resuelve?

El análisis de datos permite:

- Recomendar contenido personalizado
- Mejorar la experiencia del usuario
- Reducir costos
- Mantener usuarios activos



## ¿Por qué no bastaría Excel?

Excel no sería suficiente porque:

- Existe demasiado volumen de datos
- Los datos se generan rápidamente
- Hay millones de registros diarios
- Se necesita procesamiento en tiempo real

Por eso se utilizan tecnologías Big Data.
